Small Python 3.13 program, standard library only. It creates the output directory and writes the 237 code point story to `entry.txt` as UTF-8 with no trailing newline. Run it with `MAKEFUN_OUTPUT_DIR=/tmp/curout python3 main.py`, which writes `/tmp/curout/entry.txt`; without the variable it writes `/output/entry.txt`.
